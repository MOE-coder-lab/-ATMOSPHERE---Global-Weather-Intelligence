<h2>🌐 ABOUT THE PROJECT</h2>

<p>
ATMOSPHERE is an interactive global weather intelligence
application developed to provide users with access to
weather conditions, forecasts and historical weather
information across different geographical locations.
</p>

<p>
Built using HTML5, CSS3 and Vanilla JavaScript,
the application demonstrates practical frontend
development, API integration, asynchronous programming,
data presentation and error handling.
</p>

<h2>✨ CORE FEATURES</h2>

<h3>🌍 1. Global City Search</h3>
<p>
Search for cities across the world and retrieve
location-based weather information.
</p>

<h3>🌤️ 2. Current Weather Conditions</h3>
<ul>
  <li>Temperature and feels-like temperature</li>
  <li>Humidity</li>
  <li>Wind speed and wind gusts</li>
  <li>Atmospheric pressure</li>
  <li>Precipitation</li>
  <li>UV index</li>
  <li>Sunrise and sunset information</li>
</ul>

<h3>🌡️ 3. Temperature Conversion</h3>
<p>
Switch between Celsius and Fahrenheit temperature
measurements.
</p>

<h3>📅 4. Five-Day Weather Forecast</h3>
<p>
Explore upcoming weather conditions, daily temperature
ranges and precipitation probabilities.
</p>

<h3>📊 5. Temperature Outlook</h3>
<p>
Explore temperature trends through visual weather
data presentations.
</p>

<h3>🕰️ 6. Historical Weather Explorer</h3>
<p>
Explore available historical weather records using
date selections and weather statistics.
</p>

<h3>⚠️ 7. API Error Monitoring</h3>
<p>
Identify failed weather requests, connectivity problems
and external service errors.
</p>

<h3>🕒 8. Last Successful Update</h3>
<p>
Display the time of the last successfully retrieved
weather information.
</p>

<h3>📱 9. Responsive Design</h3>
<p>
Designed for mobile phones, tablets and desktop devices.
</p>

<h3>🧪 10. Automated Testing</h3>
<p>
Includes automated checks for temperature conversion,
weather identification, HTML escaping and numerical
data handling.
</p>

<h2>⚙️ HOW IT WORKS</h2>

<ol>
  <li>User searches for a city.</li>
  <li>The Geocoding API identifies the location.</li>
  <li>The application retrieves geographical coordinates.</li>
  <li>The weather API provides available weather information.</li>
  <li>JavaScript processes and displays the information.</li>
  <li>Users explore forecasts and historical records.</li>
</ol>

<h2>🧪 QUALITY ASSURANCE</h2>

<p>
The application includes eight automated functional
checks covering:
</p>

<ul>
  <li>Celsius-to-Fahrenheit conversion</li>
  <li>Boiling-point temperature conversion</li>
  <li>Weather code identification</li>
  <li>Clear weather identification</li>
  <li>Unknown weather code handling</li>
  <li>HTML escaping</li>
  <li>Valid numerical formatting</li>
  <li>Missing numerical data handling</li>
</ul>

<p>
<strong>Development status:</strong> The latest recorded
test run passed 6 out of 8 tests. Numerical formatting
and missing numerical data handling still require
correction and verification.
</p>

<h2>🔐 RELIABILITY AND LIMITATIONS</h2>
