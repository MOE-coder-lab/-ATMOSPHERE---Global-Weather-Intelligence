## 🌤️ About the Project

Weather influences almost every part of human life.

It affects how we travel, work, farm, plan our activities, protect our communities, and prepare for tomorrow.

Yet, understanding weather information should not be complicated.

**ATMOSPHERE – Global Weather Intelligence** was created around this simple idea: make weather information easier to access, explore, and understand through a clean, modern, and interactive digital experience.

ATMOSPHERE is an independent web development project that brings together real-time weather information, international city search, five-day forecasts, historical weather exploration, and useful weather indicators in one responsive platform.

This project represents my commitment to learning, building practical solutions, solving problems, and transforming technical knowledge into something people can interact with.

---

## 🎯 Project Objectives

The goal of ATMOSPHERE is to:

- Make weather information accessible across different locations.
- Help users explore current weather conditions.
- Present upcoming weather forecasts in an understandable format.
- Provide access to historical weather information.
- Make weather data easier to interpret through visual presentation.
- Create a responsive experience across desktop and mobile devices.
- Demonstrate practical API integration and front-end development skills.

## 🔌 API Integration

ATMOSPHERE uses Open-Meteo services to retrieve weather-related information.

The project integrates:

- **Weather Forecast API:** For current weather information and forecast data.
- **Geocoding API:** For searching and identifying geographical locations.
- **Historical Weather API:** For exploring historical weather information.

API documentation:

- https://open-meteo.com/
- https://open-meteo.com/en/docs
- https://open-meteo.com/en/docs/geocoding-api
- https://open-meteo.com/en/docs/historical-weather-api

Weather information depends on API availability, network connectivity, and the data returned by the external services.
